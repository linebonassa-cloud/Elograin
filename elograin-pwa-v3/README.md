# 🌿 Elograin v3

SuperApp Vegano com Swipe to Delete, Lixeira sempre visivel, Skeleton Screens, Google Maps API e OpenStreetMap.

## ✨ Novidades da v3

- **🗑️ Botao de Lixeira** sempre visivel no canto superior direito de cada post do feed
- **👆 Swipe to Delete** - Ao tocar na lixeira, abre modal com barra arrastavel
- **➡️ Arraste para Confirmar** - Barra vermelha que desliza da esquerda para direita dentro de uma track. Ao atingir 85%, confirma a exclusao
- **🦴 Skeleton Screens** - Shimmer nos feeds de carregamento
- **🗺️ OpenStreetMap + Leaflet** - Mapa real com coordenadas lat/long
- **🔑 Google Places API** - Busca restaurantes veganos reais (opcional)

## 🚀 Deploy no Vercel

1. Baixe o `.zip` e extraia a pasta `elograin-pwa-v3`
2. Acesse [vercel.com](https://vercel.com)
3. "Add New..." → "Project" → Arraste a pasta

## 📱 Instalar no Celular

Acesse o URL no Chrome/Safari → "Adicionar a Tela Inicial" → Funciona como app nativo offline!

## 🛠 Tecnologias

- HTML5, CSS3, JavaScript Vanilla
- Leaflet.js + OpenStreetMap
- Google Places API (New) REST
- Service Worker (offline)
- LocalStorage (persistencia)
