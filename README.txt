Elograin v7.3 - App Completo + Chatbot Elo Integrado

Arquivos incluídos neste pacote:
- index.html: Estrutura da aplicação (Header, Sidebar, Abas, Mapa e Widget do Chatbot)
- style.css: Estilos CSS com suporte a tema escuro/claro e design responsivo
- app.js: Código JavaScript completo gerindo navegação por abas, mapa Leaflet, feed da comunidade e o Chatbot Elo.

Como utilizar:
1. Extraia o conteúdo do arquivo ZIP.
2. Abra o arquivo `index.html` em qualquer navegador web.
